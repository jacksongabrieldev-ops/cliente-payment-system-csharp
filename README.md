# Sistema de Controle de Clientes e Pagamentos

Projeto desenvolvido em C# utilizando .NET Framework com o objetivo de gerenciar clientes e registrar pagamentos.

## 📌 Funcionalidades

- Cadastro de clientes
- Registro de pagamentos
- Listagem de clientes
- Listagem de pagamentos
- Identificação de pagamentos pendentes
- Geração de relatórios simples

## 🛠 Tecnologias utilizadas

- C#
- .NET Framework
- Programação Orientada a Objetos (POO)

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar conceitos de lógica de programação, manipulação de dados e organização de código utilizando C#.

## 📂 Estrutura do projeto

Models → classes do sistema  
Services → regras de negócio  
Controllers → controle das funcionalidades

## 🚀 Aprendizados

- Estruturação de aplicações em C#
- Uso de Programação Orientada a Objetos
- Manipulação de dados em aplicações
